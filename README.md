# Library Management System

A Database Management System (DBMS) project developed using **MySQL** to efficiently manage library operations such as book cataloging, member registration, book issue/return tracking, reservations, and fine management.

## Features

- Book Catalog Management
- Member Registration and Management
- Author and Publisher Tracking
- Book Issue and Return Management
- Fine Calculation and Tracking
- Reservation Management
- Entity Relationship (ER) Diagram
- Relational Database Design
- SQL Queries for Data Retrieval and Analysis

## Technologies Used

- MySQL
- DBeaver (Database Design & ER Diagram)
- SQL

## Database Modules

- Member Management
- Book Management

- Publisher Management
- Category Management
- Librarian Management
- Issue Record Management
- Return Record Management
- Fine Management
- Reservation Management

## Database Schema

The project consists of the following tables:

1. Category
2. Publisher
3. Author
4. Member
5. Librarian
6. Book
7. Book_Author
8. Issue_Record
9. Return_Record
10. Fine
11. Reservation
12. Branch
